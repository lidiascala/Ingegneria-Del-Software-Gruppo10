# Prenotazione Aule

Sistema software per la gestione e la prenotazione delle aule universitarie.

## Descrizione
Il progetto ha l'obiettivo di sviluppare un sistema che consenta
di gestire le aule e le relative prenotazioni, facilitando
l'organizzazione e l'utilizzo degli spazi universitari.

## Tecnologie utilizzate
- Java 8
- Maven
- JUnit 5
- Git e GitHub
